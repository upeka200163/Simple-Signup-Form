## 📌 About the Project

A fun, interactive, and modern **Sign-Up Form** built using **HTML, CSS, and Vanilla JavaScript**.
This project features a unique **CSS-drawn panda** that reacts to user input — creating an engaging and playful user experience.

---

## 🌟 Features

### 🐼 Interactive Animation

* Panda reacts to user actions
* Covers its eyes 🫣 when typing in **Password / Confirm Password** fields

### 🎨 Pure CSS Panda

* Entire panda created using **CSS only**
* No images or external graphics used

### 🎯 Modern UI Design

* Warm yellow background
* Stylish dark panda theme
* Clean and minimal layout

### 🐾 Detailed Elements

* Realistic panda paws
* Smooth animation transitions

### 💻 User-Friendly Form

* Clean registration card
* Input icons
* Social login buttons (Facebook & Gmail)
* “Login Now” toggle

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/upeka200163/Simple-Signup-Form.git
```

### 2. Navigate to project folder

```bash
cd Simple-Signup-Form
```

### 3. Open the project

```bash
Open index.html in your browser
```

---

## 💡 How It Works

* JavaScript listens for input focus events
* When password fields are selected, CSS animations trigger
* Panda covers its eyes for a fun interaction
